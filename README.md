# 검 강화 대장간 · 웹 버전 무료 배포 안내

claude.ai 아티팩트 버전과 같은 게임이에요. 로그인과 저장을 **Supabase**(무료 데이터베이스)로,
웹 주소를 **Netlify**(무료 호스팅)로 처리해서 claude.ai 계정이 없는 친구도 이메일로 가입해 함께 할 수 있어요.

```
sword-forge-web/
├─ index.html          게임 본체
├─ config.js           Supabase 주소와 키를 넣는 곳 (내가 고치는 파일은 이것 하나)
└─ supabase/schema.sql 테이블, 접근 규칙, 결투 함수
```

걸리는 시간: 처음 한 번 15분쯤. 돈은 들지 않아요.

---

## 0. 준비

1. 받은 `sword-forge-web.zip` 을 압축 해제해요. 폴더 안에 `index.html`, `config.js`, `supabase` 폴더가 바로 보여야 해요.
2. 가입에 쓸 이메일이나 GitHub 계정을 준비해요.

## 1. Supabase 프로젝트 만들기

1. https://supabase.com 에서 **Start your project** → GitHub 또는 이메일로 가입해요.
2. **New project** 를 눌러요.
   - Name: 아무거나 (예: `sword-forge`)
   - Database Password: 자동 생성 버튼을 누르고, 어딘가에 적어 두세요. 게임에는 쓰지 않아요.
   - Region: **Northeast Asia (Seoul)** — 한국에서 가장 빨라요.
   - Plan: **Free**
3. **Create new project** 를 누르고 1~2분 기다리면 대시보드가 열려요.

## 2. 테이블 만들기 (SQL 실행)

1. 왼쪽 메뉴 **SQL Editor** → **New query**.
2. `supabase/schema.sql` 을 메모장(맥은 텍스트 편집기)으로 열어 **전체 내용**을 복사해 붙여넣어요.
3. 오른쪽 아래 **Run**. `Success. No rows returned` 가 나오면 성공이에요.
   - 경고 창("destructive operation" 등)이 뜨면 내용을 확인하고 실행을 눌러요. 이 SQL은 여러 번 실행해도 기존 저장을 지우지 않아요.

## 3. 이메일 인증 끄기 (친구끼리라면 추천)

기본값은 가입하면 확인 메일이 가고, 링크를 눌러야 로그인할 수 있어요.
Supabase 무료 메일 발송은 시간당 몇 통으로 제한돼 있어서, 친구 여럿이 한꺼번에 가입하면 메일이 안 갈 수 있어요.

1. 왼쪽 메뉴 **Authentication** → **Sign In / Providers** → **Email**.
2. **Confirm email** 을 끄고 **Save**.

이러면 가입하자마자 바로 플레이할 수 있어요. (끄지 않는다면 6단계를 꼭 하세요.)

## 4. 주소와 키를 config.js 에 넣기

1. Supabase 대시보드 위쪽 **Connect** 버튼, 또는 **Project Settings → API Keys / Data API** 에서 두 값을 찾아요.
   - **Project URL**: `https://abcdefghijk.supabase.co` 처럼 생겼어요.
   - **Publishable key**: `sb_publishable_` 로 시작해요.
     예전 프로젝트라 이 키가 없으면 **Legacy API Keys** 탭의 `anon` `public` 키를 써도 돼요.
   - ⚠️ **Secret key**(`sb_secret_`)나 **service_role** 키는 절대 넣지 마세요. 이 키는 모든 접근 규칙을 무시해요.
2. `config.js` 를 메모장으로 열어 따옴표 안을 바꾸고 저장해요.

```js
window.FORGE_CONFIG = {
  supabaseUrl: 'https://abcdefghijk.supabase.co',
  supabaseAnonKey: 'sb_publishable_xxxxxxxxxxxxxxxx',
};
```

따옴표(`'`)와 쉼표(`,`)는 지우지 마세요.

## 5. Netlify 에 올리기

1. https://app.netlify.com/signup 에서 **먼저 무료 가입**해요 (GitHub 또는 이메일).
   가입하지 않고 올려도 되지만, 그러면 일정 시간 안에 사이트를 "내 것으로 등록"하지 않으면 사라져요.
2. 로그인한 상태로 https://app.netlify.com/drop 을 열어요.
3. 압축을 푼 **`sword-forge-web` 폴더를 통째로** 점선 상자에 끌어다 놓아요.
   (폴더를 열었을 때 `index.html` 이 바로 보이는 그 폴더예요.)
4. 몇 초 뒤 `https://무작위이름.netlify.app` 주소가 생겨요. 이게 게임 주소예요.
5. 주소를 바꾸고 싶으면 사이트 화면에서 **Site configuration → Change site name** (예: `sword-forge-ksw` → `https://sword-forge-ksw.netlify.app`).

## 6. Supabase 에 게임 주소 알려 주기

**Authentication → URL Configuration** 에서

- **Site URL** 을 5단계의 게임 주소로 바꾸고 저장해요.

확인 메일이나 비밀번호 재설정 메일의 링크가 이 주소로 돌아와요. 3단계에서 확인 메일을 껐다면 해 두기만 하면 돼요.

## 7. 잘 되는지 확인

1. 게임 주소를 열면 로그인 창이 떠요. **회원가입** 탭에서 이메일, 비밀번호(6자 이상), 닉네임을 넣어요.
2. 화면 위 계정 표시가 **"저장됨 · 시각"** 으로 바뀌면 클라우드 저장 성공이에요.
3. **친구 결투** 탭에 내 이름이 순위표에 보이면 결투 준비 끝이에요.
4. 친구에게 게임 주소를 보내 주세요. 친구가 가입하면 순위표에 나타나요.

---

## 업데이트할 때

새 압축 파일을 받으면:

1. 새 `index.html` 로 바꿔요. **내 `config.js` 는 그대로 두세요** (새 파일의 config.js 로 덮어쓰면 키가 지워져요).
2. 안내에 "schema.sql 다시 실행"이 있으면 2단계를 한 번 더 해요.
3. Netlify 사이트 화면 → **Deploys** 탭 → 폴더를 다시 끌어다 놓아요. 주소는 그대로예요.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 계정 표시가 "서버 설정 전" | `config.js` 의 주소나 키가 비었거나 `YOUR_` 가 남아 있어요. 4단계를 다시 확인하고, 저장 후 다시 올려요. |
| 가입할 때 `Invalid API key` | 키를 잘못 복사했어요. 앞뒤 공백 없이 다시 붙여넣어요. |
| "가입 확인 메일의 링크를 먼저 눌러 주세요" / 메일이 안 와요 | 3단계에서 Confirm email 을 꺼요. |
| 친구 결투에 "친구 목록을 불러오지 못했어요" | `schema.sql` 이 끝까지 실행되지 않았어요. 2단계를 다시 해요. |
| 한동안 안 했더니 로그인이 안 돼요 | Supabase 무료 프로젝트는 일주일쯤 아무도 안 쓰면 잠들어요. 대시보드에서 **Restore project** 를 누르면 저장 그대로 깨어나요. |

## 무료 한도

친구 몇십 명이 하기에는 넉넉해요.

- Supabase 무료: 데이터베이스 500MB, 한 달 활성 사용자 5만 명. 이 게임의 저장은 한 사람당 20~40KB예요.
- Netlify 무료: 이 게임처럼 작은 정적 사이트는 여유롭게 들어가요.

## 저장 방식

- 로그인하면 진행 상황이 `saves` 테이블에 계정마다 한 줄로 저장돼요. 8초마다 몰아서 저장하고,
  탭을 닫거나 다른 탭으로 넘어갈 때 바로 저장해요.
- 다른 기기에서 더 최근에 저장했으면, 탭으로 돌아올 때와 1분마다 확인해서 자동으로 불러와요.
- 처음 로그인하면 이 브라우저에서 하던 진행 상황을 계정에 올려요.
  계정에 이미 저장된 게 있으면 그쪽을 불러와요.
- 로그인하지 않고 할 수도 있어요. 그때는 그 브라우저에만 저장돼요.
- 접근 규칙(RLS) 덕분에 다른 사람의 저장은 읽을 수도 고칠 수도 없어요.
  닉네임과 결투 기록만 로그인한 사람끼리 볼 수 있어요.

## 친구 결투

- **친구 결투** 탭에서 같은 주소로 가입한 친구들의 순위표를 보고 도전할 수 있어요.
- 상대가 접속해 있지 않아도, 상대가 마지막으로 저장한 출전 검과 싸워요.
- 이길 확률은 전투력 차이로 정해져요. 전투력은 출전 검 단계에 경매 보물(개당 0.2), 던전 보물(개당 0.3), 혼(개당 0.02, 100개까지)을 더한 값이에요.
- 승패는 Supabase의 `duel_fight` 함수가 서버에서 정해요. 양쪽에 같은 결과가 남고,
  명예 점수(체스식, 1000점에서 시작)와 결투 기록은 브라우저에서 고칠 수 없어요.
- 이기면 상대 검 단계에 따라 상금을 받아요. 같은 상대를 10분 안에 다시 이기면 명예 점수만 오르고 상금은 없어요.
- 져도 골드나 검은 잃지 않아요. 결투는 10초에 한 번 신청할 수 있고, 출전 검이 던전에 있으면 도전할 수 없어요.

## 알아 둘 점

- 강화, 던전 같은 게임 계산은 브라우저에서 돌아가요. 결투의 승패는 서버가 정하지만,
  결투에 쓰이는 검 단계는 각자의 저장 데이터를 따르기 때문에 마음먹으면 조작할 수 있어요.
  친구끼리 즐기는 용도로 생각해 주세요.
- 이 버전은 claude.ai 아티팩트로 올릴 수 없어요. 아티팩트는 외부 서버 연결이 막혀 있어요.
- 아티팩트 버전과 저장이 따로예요. 아티팩트에서 하던 진행 상황은 넘어오지 않아요.
